Lahore Twin github.com/hammasbuilds/lahore-twin

What happens between typing a value and seeing the simulated result.
One offline web app over stdlib-Python simulators; a local server re-runs a module with your values. No model, no embedding, no vector store.

Input

a module and the values typed into its form

Output

the module's dashboard on a fresh simulation
