Lahore Twin · Lahore traffic github.com/hammasbuilds/lahore-twin

One real vehicle from the evening: why it drove, the shop it stopped at, the signal it met.
A microscopic traffic simulation (car-following + lane changing) on OpenStreetMap roads; signal controllers are rules. No model, no embedding, no vector store.

Input

an evening peak, 8,000 trips an hour, real roads and places

Output

delay, stops, signal losses, busiest places, per signal plan
